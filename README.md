# Flappy Bird 3D (React + TypeScript + Vite)

A simple Flappy Bird game built with React, TypeScript, and Vite. Play as a bird and try to fly through as many pipes as possible without crashing!

## Features

- Responsive canvas-based gameplay
- Smooth animations and physics
- Score and high score tracking
- Keyboard and mouse controls
- Modern UI with Tailwind CSS

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm

### Installation

```sh
npm install
```

### Running the Game

Start the development server:

```sh
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to play.


## Controls

- **SPACE** or **Click**: Flap the bird to fly
- Avoid the green pipes and don't hit the ground or ceiling!
